## 🚀 Featured Project

# BuildGuardAI

### An Intelligent System for Automated Building Boundary and Floor-Limit Violation Detection

BuildGuardAI is an AI-based system designed to assist in identifying changes in buildings using satellite imagery.

### Problem

Government officials may need to inspect buildings manually across different areas. This can require considerable time and manpower, while newly constructed or modified buildings may be difficult to identify through manual inspection alone.

### Solution

The system compares old and new satellite images using AI.

When a new building is constructed or an existing building is modified, the system detects the change and marks the location for further verification.
